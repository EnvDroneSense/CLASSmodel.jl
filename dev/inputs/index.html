Input information

input_info(name) returns the title, unit, symbol and slider range of a ModelInput field. The slider range is not a validity rule. validate checks the input when ModelInput is constructed and throws an ArgumentError if the input cannot be run.

input_info(:sinperiod)
(title = "Half period of the flux cycle", unit = "s", symbol = "T_sin", min = 3600, max = 86400)
