Outputs

Output table

The output is a NamedTuple of vectors, so it is also a table in the sense of Tables.jl: DataFrame(out) and CSV.write("run.csv", out) work once those packages are loaded. out.t is the time in hours since midnight of the start day.

Units

wCO2 and the fluxes wCO2* in the output are in mg CO2 m-2 s-1. The mixed-layer concentrations CO2 and dCO2 are in ppm. The 22 species are in ppb.

Output information

variable_info(name) returns the title, unit and symbol of an output variable.

variable_info(:k_r05)
(title = "NO2 photolysis rate", unit = "s-1", symbol = "k_r05")

Mixed-layer profile

mixed_layer_profile(input, out, i) gives the corner points (z, theta, q) of the profiles at output row i. The profile is constant up to h, has a jump at h, then follows the lapse rates of the input up to ztop (default 2h).

x = ModelInput()
out = run_model(x)
mixed_layer_profile(x, out, length(out.t))
(z = [0.0, 1534.205177938003, 1534.205177938003, 3068.410355876006], theta = [295.16733364798, 295.16733364798, 297.005231067628, 306.210462135256], q = [0.009944673017558027, 0.009944673017558027, 0.00700000000000001, 0.00700000000000001])
