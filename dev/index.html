CLASSmodel

CLASS, the Chemistry Land-surface Atmosphere Soil Slab model, is a mixed-layer model of the convective boundary layer coupled to a land surface. This package is a Julia version of the Python model modelpy.

Quick start

using CLASSmodel

x = ModelInput(; runtime = 12 * 3600, dt = 60)   # the default case: a dry, growing mixed layer
out = run_model(x)
(h = out.h[end], theta = out.theta[end], q = out.q[end])
(h = 1534.205177938003, theta = 295.16733364798, q = 0.009944673017558027)

The output is a NamedTuple of vectors, so it is also a table in the sense of Tables.jl: DataFrame(out) and CSV.write("run.csv", out) work once those packages are loaded. out.t is the time in hours since midnight of the start day.

Switches

Every component is off by default and is switched on in the input.

SwitchComponent
sw_mlmixed-layer growth, entrainment and tendencies (default on)
sw_shearweshear contribution to entrainment
sw_fixftfree troposphere fixed under subsidence
sw_windprognostic wind
sw_slsurface layer: ustar, drag coefficients, 2 m diagnostics
sw_radradiation: solar angle, net radiation
sw_lsland surface, with ls_type = :js (Jarvis-Stewart) or :ags (A-Gs, needs sw_rad)
sw_cushallow cumulus: mass flux and cloud core fraction
x = ModelInput(; sw_rad = true, sw_sl = true, sw_ls = true, ls_type = :ags, c3c4 = :c4)
out = run_model(x)
(H = maximum(out.H), LE = maximum(out.LE), wCO2A = minimum(out.wCO2A))
(H = 168.8638065319344, LE = 92.51851919325179, wCO2A = -0.5163954825014517)

Step by step

s = init_model(ModelInput(; runtime = 600))
step!(s)
s.mixed_layer.h
201.70267080220611

Units

wCO2 and the fluxes wCO2* in the output are in mg CO2 m-2 s-1; the mixed-layer concentrations CO2 and dCO2 are in ppm.

  • ls_type is :js (Jarvis-Stewart) or :ags (A-Gs); c3c4 is :c3 or :c4.

CLASSmodel.run_model — Method
run_model(input; constants = PhysicalConstants{T}()) -> ModelOutput

Run the model for floor(runtime / dt) steps and return the time series. Each row holds the state before the time step is integrated.

CLASSmodel.step! — Method
step!(s::ModelState)

Advance the model by one time step: compute the components, then integrate the land surface and the mixed layer. The diagnostics of the step are left in s.

CLASSmodel.validate — Method
validate(input::ModelInput)

Throw an ArgumentError if input cannot be run. Called by the ModelInput constructor. Checks:

  • every numeric field is finite
  • positive time step, run time, h, Ps, z0m, z0h
  • dtheta != 0 when the mixed layer or the cumulus scheme is on
  • 0 <= cc <= 1, 0 <= cveg <= 1, 0 <= c_beta <= 1
  • ls_type and c3c4 have a known value
  • with sw_ls: LAI, Wmax, wg > 0, 0 < w2 < wsat and wwilt < wfc <= wsat
  • with sw_cu: dz_h > 0
  • A-Gs (sw_ls with ls_type = :ags) needs sw_rad, because it uses the incoming shortwave radiation
