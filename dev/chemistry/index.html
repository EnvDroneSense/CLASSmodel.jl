Species and chemistry

Chemical species

The model carries 22 species. Their names are in CLASSmodel.SPECIES. The input tuples C, dC, gammaC, advC, wC and sw_wC hold one value for each species, in that order. The mixing ratios are in ppb and the surface fluxes are in ppb m s-1. The output has one column for each species. The species are transported like CO2.

sw_wC sets the surface flux of each species:

sw_wCSurface flux
0constant wC
1wC * sin(pi t / sinperiod)
2wC times the solar elevation divided by its value at noon, zero at night

Inert takes part in no reaction. It is the passive scalar. Without sw_chem, all species are passive.

x = ModelInput(; runtime = 3600, sw_wtheta = true, sinperiod = 12 * 3600)
out = run_model(x)
(Inert = out.Inert[end], CH4 = out.CH4[end])
(Inert = 15.02599228417738, CH4 = 1724.0)

Chemistry

sw_chem runs the gas-phase reactions with an implicit Gauss-Seidel solver. The scheme has 28 reactions. sw_reactions holds one switch for each of them. Set a switch to false to turn that reaction off.

InputMeaning
sw_chem_constantthe rates use the reference state, not the mixed layer (default on)
sw_photo_constantthe photolysis uses the sun at the hour tod_ref [h UTC] (default on)
P_ref, Tcbl_ref, Tft_ref, qcbl_ref, qft_refreference pressure, temperature and humidity of the mixed layer and the free troposphere
stocoefOH yield of the reaction RO2 + HO2

The output has two extra columns: phi, the photostationary state of NO, NO2 and O3, and k_r05, the NO2 photolysis rate [s-1].

x = ModelInput(; runtime = 3600, sw_chem = true)
out = run_model(x)
(NO2 = out.NO2[end], O3 = out.O3[end], phi = out.phi[end])
(NO2 = 0.6579783927344731, O3 = 32.657295549025875, phi = 0.7579076206055084)
