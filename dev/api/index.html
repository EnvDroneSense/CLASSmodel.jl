Module

CLASSmodel.CLASSmodel — Module
CLASSmodel

CLASS, the Chemistry Land-surface Atmosphere Soil Slab model: a mixed-layer model of the convective boundary layer coupled to a land surface.

using CLASSmodel
out = run_model(ModelInput(; runtime = 12 * 3600))   # a table with one column per variable
out.h                                                # boundary-layer height [m]

For a run step by step use init_model and step!.

CLASSmodel.ModelInput — Type
ModelInput{T}(; kwargs...)
ModelInput(; kwargs...)    # T = Float64

All input of a run. The defaults describe a dry mixed layer with fixed surface fluxes. The input is checked when it is constructed (see validate).

Notes:

  • ls_type is :js (Jarvis-Stewart) or :ags (A-Gs); c3c4 is :c3 or :c4.
  • wCO2 is in mg CO2 m-2 s-1 (converted with mair / (rho * mco2)).
  • c_beta = 0 is a linear water stress response.
  • The 22 species of CLASSmodel.SPECIES are in ppb. Inert takes part in no reaction: it is the passive scalar. Without sw_chem all species are passive. sw_wC is the flux mode of each: 0 constant wC, 1 wC * sin(pi t / sinperiod), 2 wC times the solar elevation divided by its noon value (zero at night).
  • sw_chem runs the reactions of sw_reactions (see chemistry!). sw_chem_constant takes pressure, temperature and humidity from the reference state (P_ref, Tcbl_ref, Tft_ref, qcbl_ref, qft_ref: mixed layer and free troposphere) and not from the mixed layer. sw_photo_constant fixes the sun of the photolysis at the hour tod_ref [h UTC] in the day. stocoef is the OH yield of the reaction RO2 + HO2.
  • sw_curad has an effect only with sw_cu and sw_rad; without it, radiation uses cc.
  • sw_sea has an effect only with sw_ls: fixed Ts, open-water evaporation, no soil.

CLASSmodel.validate — Function
validate(input::ModelInput)

Throw an ArgumentError if input cannot be run. Called by the ModelInput constructor. Checks:

  • every numeric field is finite
  • positive time step, run time, sinperiod, h, Ps, z0m, z0h
  • dtheta != 0 when the mixed layer or the cumulus scheme is on
  • 0 <= cc <= 1, 0 <= cveg <= 1, 0 <= c_beta <= 1
  • C >= 0 and sw_wC is 0, 1 or 2 for every species
  • 0 <= tod_ref <= 24, P_ref, Tcbl_ref, Tft_ref > 0, qcbl_ref, qft_ref, stocoef >= 0
  • ls_type and c3c4 have a known value
  • with sw_ls and not sw_sea: LAI, Wmax, wg > 0, 0 < w2 < wsat and wwilt < wfc <= wsat
  • with sw_cu: dz_h > 0
  • A-Gs (sw_ls without sw_sea, ls_type = :ags) needs sw_rad, because it uses the incoming shortwave radiation

Run

CLASSmodel.run_model — Function
run_model(input; constants = PhysicalConstants{T}(), progress = nothing,
    progress_every = 100) -> ModelOutput

Run the model for floor(runtime / dt) steps and return the time series. Each row holds the state before the time step is integrated. With ls_type = :ags it throws a DomainError when the vapour pressure deficit is above f0 / ad (C3 12.7 kPa, C4 5.7 kPa).

progress(i, n, out) is called after every progress_every steps and after the last step n. The rows after i of out are still zero. If it returns false, the run stops and the output holds the rows 1:i.

Advance the model by one time step: compute the components, then integrate the land surface and the mixed layer. The diagnostics of the step are left in s.

Output

CLASSmodel.ModelOutput — Type
ModelOutput{T}

Time series of one run: a NamedTuple with one vector per variable (a table in the sense of Tables.jl). t is the time in hours since midnight of the start day, so it exceeds 24 in runs longer than a day. wCO2* are in mg CO2 m-2 s-1.
