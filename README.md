[![Coverage](https://codecov.io/gh/EnvDroneSense/CLASSmodel.jl/branch/main/graph/badge.svg)](https://codecov.io/gh/EnvDroneSense/CLASSmodel.jl)

A Julia implementation of CLASS, the Chemistry Land-surface Atmosphere Soil Slab model: a mixed-layer model of the convective boundary layer coupled to a land surface. It is a port of [modelpy](https://github.com/classmodel/modelpy), the Python version of CLASS. The package is under development and not yet usable.
